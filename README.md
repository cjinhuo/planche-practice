# 悬空之前 · 30天俄挺训练手册

每周5练2休的俄挺入门训练网页，含动作图解、逐组记录、计时与手动阶段切换。

无需登录。训练记录保存在访问者当前浏览器的localStorage中，不会上传服务器，也不跨设备同步。

具体训练量是以标准俯卧撑20次、至少2组的自述基础编排的初始方案；进阶按动作质量与恢复表现调整。

## 内容与素材来源

- 动作示意SVG：本项目制作。
- 标注“原视频参考”的5张低分辨率参考帧来自 [努力的小易_ 的原视频](https://www.bilibili.com/video/BV1Y1Je6uE9i)，保留原画面与水印，用于教学讨论与姿势对照；未包含原视频文件。
- 俄挺训练原则：[GMB](https://gmb.io/planche/)。
- 臀桥动作参考：[ACE](https://www.acefitness.org/resources/everyone/exercise-library/49/glute-bridge/)。

网页使用原生HTML/CSS/JavaScript，静态部署无需构建。
